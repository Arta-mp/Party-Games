# 🎉 بازی‌های گروهی (Party Games)

وب‌اپ فارسی و اپن‌سورس برای بازی‌های گروهی. روی موبایل مثل اپ نصب می‌شود (PWA)، روی GitHub Pages رایگان میزبانی می‌شود و **بدون سرور** کار می‌کند:

- **آنلاین:** هر نفر با گوشی خودش؛ لابی با کد ۴ حرفی، لینک دعوت و QR. گوشی میزبان خودش سرور بازی است و ارتباط مستقیم بین گوشی‌هاست (WebRTC با Trystero).
- **یک گوشی (Pass & Play):** گوشی دست‌به‌دست می‌شود؛ بدون اینترنت و حتی آفلاین.
- **بدون ثبت‌نام:** فقط یک نام کاربری که روی دستگاه ذخیره می‌شود.

## ✏️ محتوای کاستوم

- **نقش توانایی‌دار** برای مافیا/گرگینه با ویرایشگر مرحله‌به‌مرحله (تیم، اکشن شب، تعداد دفعات، اولویت، ویژگی‌های غیرفعال، شرط برد) و **نشانگر تعادل**.
- **نقش اطلاعاتی** برای خانواده‌ی جاسوس (چه می‌بیند / چه کسی را می‌شناسد / چطور می‌برد).
- **پک محتوا** برای همه‌ی بازی‌ها (کلمه با دسته و سختی، مکان، جفت‌کلمه، کارت ممنوعه، طیف، سؤال، …).
- همه‌چیز فقط **داده** است (بدون eval)، با Zod اعتبارسنجی می‌شود و با یک لینک `#/import/…` (فشرده با lz-string) یا فایل JSON به اشتراک گذاشته می‌شود. محتوای کاستوم هنگام شروع بازی همراه تنظیمات فرستاده می‌شود و بقیه لازم نیست نصبش کنند.
- پک‌های پیشنهادی را با Pull Request به [`src/content/packs/`](src/content/packs) اضافه کنید؛ CI همه را با Zod چک می‌کند.

## 🧱 معماری

```text
src/
  core/engine/    GameModule، GameRunner، RNG seed‌دار، تایمر endsAt
  core/net/       Transport + PeerTransport (پروتکل اعلام میزبان) ← Trystero / BroadcastChannel / Local
  core/lobby/     لابی خالص، HostSession (host-authoritative)، ClientSession، انتخاب میزبان
  core/identity/  نام کاربری، deviceId، آواتار رنگی
  games/          registry (lazy) + یک پوشه برای هر خانواده
  content/packs/  پک‌های JSON فارسی
  custom/         اسکیماهای نقش، ویرایشگرها، کد اشتراک
  i18n/           fa.ts و en.ts
  ui/             Design System (توکن‌ها در styles.css)
```

- منطق هر بازی یک **reducer خالص** است که از شبکه چیزی نمی‌داند؛ میزبان اکشن‌ها را با Zod اعتبارسنجی و اجرا می‌کند و برای هر بازیکن **فقط نمای خودش** را با `toPeer` می‌فرستد. `broadcast` فقط برای وضعیت عمومی لابی است، پس هیچ رازی پخش همگانی نمی‌شود.
- تایمرها زمان مطلق میزبان (`endsAt`) هستند و اختلاف ساعت گوشی‌ها جبران می‌شود.
- اتصال مجدد با deviceId (۶۰ ثانیه مهلت)، ذخیره‌ی State میزبان در localStorage (رفرش میزبان بازی را خراب نمی‌کند)، انتقال دستی میزبان با Snapshot و انتخاب خودکار میزبان جدید با epoch.

## 🌐 اتصال آنلاین در ایران

از تنظیمات می‌شود روش سیگنالینگ را بین **Nostr / MQTT / Torrent** عوض کرد (همه‌ی بازیکن‌ها باید یک روش داشته باشند) و برای اپراتورهای موبایلی که NAT سخت دارند یک **سرور TURN** اختیاری تعریف کرد. اگر هیچ‌کدام وصل نشد، حالت «یک گوشی» همیشه کار می‌کند. تست واقعی اتصال در ایران هنوز باید انجام شود (فاز ۲ در PLAN.md).

## 🛠️ توسعه

</div>

```bash
pnpm install
pnpm dev            # http://localhost:5173
pnpm test           # unit tests (Vitest): reducers, secrecy, lobby over in-memory network, packs, i18n
pnpm e2e            # Playwright (builds first): pass & play, 4-tab online round, all 24 modes, PWA offline
pnpm lint && pnpm typecheck && pnpm format:check
pnpm build && pnpm preview --port 4173 & pnpm lighthouse   # mobile Lighthouse, fails under 90
ANALYZE=1 pnpm build   # bundle treemap (stats.html)
```
